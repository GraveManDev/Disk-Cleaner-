# 🚀 Очистка диска C: - Удобный инструмент для оптимизации пространства

**✨ Описание:**  
Этот инструмент поможет вам быстро и безопасно очистить диск C: от ненужных файлов, включая:  
- 📁 Временные файлы  
- ♻️ Файлы-дубликаты  
- 🗃️ Кэш приложений  
- ...и многое другое!

---

## 🔥 Возможности
- **Гибкая настройка** - выбирайте, что именно нужно очистить  
- **Безопасность** - удаляются только ненужные файлы, системные файлы не затрагиваются  
- **Простота** - интуитивно понятный интерфейс  
- **Бесплатно** - никаких скрытых платежей или подписок  

---

## 📥 Установка
1. Перейдите во вкладку [Releases](https://github.com/GraveManDev/Disk-Cleaner-/releases/tag/V1.0)  
2. Скачайте последнюю версию `.exe` файла  
3. Запустите и следуйте инструкциям
